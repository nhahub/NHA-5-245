SLA Guard endpoints

n8n webhook

POST http://localhost:8080/webhook/sla-guard

Send Content-Type: application/json and X-SLA-Key: <SLA_WEBHOOK_KEY>.

status

Read the current status and recent checks. Defaults to the live dataset.

{"action":"status"}
check

Probe the website now and store one live check.

{"action":"check"}
report

Generate a monthly report. Omit the month to use the previous UTC month.

{"action":"report","dataset":"demo"}
get_report

Read a saved report and its draft. Supply the month as YYYY-MM in UTC.

{"action":"get_report","dataset":"demo","month":"2026-10"}

Demo site

  • GET /health

    Returns HTTP 200 when up and HTTP 503 during a simulated outage.

  • POST /admin/down

    Simulate an outage.

  • POST /admin/up

    Restore the demo site.

Both admin routes require Authorization: Bearer <DEMO_CONTROL_TOKEN>.
